# Project 1 - Wordle Game 

Submitted by: Jesse Rosenthal

Wordle Game App is an app that is a daily word puzzle game where players try to guess a secret 5-letter word in 6 attempts or fewer. 
How It Works:

The Goal: Guess a hidden 5-letter word
6 Attempts: You have 6 tries to get it right
Color-Coded Feedback: After each guess, you get clues:

🟩 Green: Correct letter in the correct position
🟨 Yellow: Correct letter but in the wrong position
⬜ Gray: Letter is not in the word at all

Game Flow:

Type a 5-letter word using the on-screen keyboard
Press ENTER to submit your guess
See the color feedback for each letter
Use the clues to make your next guess
Win by guessing the word, or lose after 6 failed attempts

Example:
If the secret word is PLANT and you guess TRAIN:

T = Gray (not in PLANT)
R = Gray (not in PLANT)
A = Yellow (in PLANT but wrong position)
I = Gray (not in PLANT)
N = Yellow (in PLANT but wrong position)

Time spent: 15 hours spent in total
